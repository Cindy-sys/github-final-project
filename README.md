# github-final-project

This project provides a simple Bash script to calculate the simple interest based on the principal amount, annual rate of interest, and the time period.

## Functionality
The script takes three inputs from the user:
1. **Principal Amount**: The initial sum of money.
2. **Annual Interest Rate**: The interest rate per year.
3. **Time Period**: The duration in years.

It then applies the formula:  
**Simple Interest = (Principal * Rate * Time) / 100**

## Usage
To run the script, use the following commands in your terminal:
```bash
chmod +x simple-interest.sh
./simple-interest.sh
